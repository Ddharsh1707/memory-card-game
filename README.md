# Memory Card Game

Flip cards and match all the pairs in as few moves as possible.

Built with plain **HTML, CSS and JavaScript**. No libraries, no build step.

## How to run

Download or clone this repo and open `index.html` in your browser.

```bash
git clone https://github.com/Ddharsh1707/memory-card-game.git
```
